# Support

For public questions, bugs, and maintenance tasks, use GitHub Issues.

Use the security policy for vulnerability reports or anything that could expose private data:

- [SECURITY.md](SECURITY.md)

Before opening an issue, please check:

- [README.md](README.md)
- [docs/reviewer-guide.md](docs/reviewer-guide.md)
- [docs/local-demo-walkthrough.md](docs/local-demo-walkthrough.md)
- [docs/privacy.md](docs/privacy.md)

This public edition is maintained as a source release. It does not provide hosted accounts or support for private operational data.
